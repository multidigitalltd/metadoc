תוסף זמני לשליחת לידים שנשלחו בהצלחה מהאתר ל-CRM של מערכת הפרסום (bhol),
לצורך מדידת קמפיין. מפעילים בזמן הקמפיין ומכבים בסיומו ממסך התוספים.

== התקנה ==
1. לוח בקרה → תוספים → הוספת תוסף → העלאת תוסף → בחרו את הקובץ
   metadoc-campaign-tracking.zip → התקן → הפעל.
2. זהו. כל ליד שנשלח בהצלחה יישלח גם ל-CRM של הקמפיין.

== כיבוי בסיום הקמפיין ==
לוח בקרה → תוספים → "Metadoc — מעקב קמפיין" → השבת (ואפשר גם להסיר).

== שינוי כתובת ה-CRM (אופציונלי) ==
ברירת המחדל: https://ext.bhol.co.il/lead.php
לשינוי ללא עריכת קוד, הוסיפו ל-functions.php של התבנית:

    add_filter( 'mdct_endpoint', function () {
        return 'https://your-crm.example.com/lead.php';
    } );

== הערות ==
- הפעולה היא fire-and-forget: אינה חוסמת ואינה משפיעה על שליחת הליד הרגילה.
- נתמכים טופס התבנית Metadoc (אירוע metadoc:lead) וגם טפסי Elementor.
- פרמטרי הקמפיין (UcId/UsId/UaId/Utype, utm_*) נקראים מכתובת הנחיתה.
- מאחר שנשלחים פרטי ליד לגורם חיצוני — ודאו שמדיניות הפרטיות מתייחסת לכך.
