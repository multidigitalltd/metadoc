# פונטים — קבצים נדרשים

העיצוב משתמש בשלושה פונטים מסחריים בעברית. כדי להגיע לדיוק 1:1 מול העיצוב,
יש להעלות לכאן את חמשת קבצי ה-`.woff` הבאים (בדיוק בשמות האלה):

| קובץ | משפחה | משקל | שימוש |
|------|--------|------|--------|
| `barlev-bold.woff`        | Barlev   | 700 | כותרות ראשיות (display) |
| `atlas-regular.woff`      | Atlas    | 400 | טקסט גוף |
| `atlas-medium.woff`       | Atlas    | 500/600 | טקסט מודגש |
| `anomalia-demibold.woff`  | Anomalia | 600 | כותרות חלופי |
| `anomalia-bold.woff`      | Anomalia | 700 | כותרות חלופי |

הקבצים מקושרים כבר ב-`tooling/input.css` (כללי `@font-face`) וב-CSS המקומפל.
ברגע שהקבצים כאן — האתר ירנדר אותם אוטומטית. עד אז יש נפילה לפונט `Assistant`.

> הקבצים לא נכללו בייצוא ה-Lovable (היו מאוחסנים ב-CDN שלהם). יש לוודא רישיון
> Web Font תקף לכל פונט לפני העלאה לאתר חי.

לאחר העלאת הפונטים אין צורך לקמפל מחדש — ההפניות כבר קיימות. (קימפול מחדש נדרש
רק אם משנים מחלקות Tailwind ב-PHP.)
