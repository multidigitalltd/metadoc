# פונטים — קבצים נדרשים

העיצוב משתמש בשתי משפחות פונט בעברית: **Anomalia** (כותרות) ו-**Atlas** (גוף).
כדי להגיע לדיוק 1:1, יש להעלות לכאן את קבצי הפונט בשמות הבאים **בדיוק**.

מומלץ **woff2** (קל ומהיר יותר). הקוד טוען woff2 ראשון ונופל ל-woff אם קיים —
אפשר להעלות woff2 בלבד.

| קובץ (woff2 מומלץ) | משפחה | משקל | שימוש |
|------|--------|------|--------|
| `atlas-regular.woff2`     | Atlas    | 400 | טקסט גוף |
| `atlas-medium.woff2`      | Atlas    | 500/600 | טקסט מודגש |
| `anomalia-demibold.woff2` | Anomalia | 600 | כותרות (demibold) |
| `anomalia-bold.woff2`     | Anomalia | 700 | כותרות (bold) |

> `atlas-medium` משרת גם 500 וגם 600 — מכוון, אין צורך בקובץ נפרד ל-600.

ההפניות מוגדרות ב-`tooling/input.css` (כללי `@font-face`) וב-CSS המקומפל.
ברגע שהקבצים כאן — האתר ירנדר אותם אוטומטית. עד אז יש נפילה לפונט `Assistant`.

## אם יש לך woff (ולא woff2)
אפשר להעלות `*.woff` באותם שמות — הקוד תומך בשניהם. (אפשר גם להעלות את שניהם.)

> ודא רישיון Web Font תקף לכל פונט לפני העלאה לאתר חי.

אין צורך לקמפל מחדש לאחר העלאת הפונטים — ההפניות כבר קיימות.
